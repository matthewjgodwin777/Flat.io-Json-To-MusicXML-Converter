It's a cost effective way to almost fully convert (with minor stuff to correct still) a flat.io json to the well known .musicxml format.
The json i refer to is the 1 massive json which comes from a single api call (which can be seen using inspect element)
which eventually renders as the sheet music you see in the website.

Since it asks to upgrade to flat.io premium which many aspiring musicians can't afford, and to easily transfer your project to other applications like musescore4, etc.,
I have made this program in python such that you just need to copy the json and use this program to simply convert it into the musicxml format!

Once its done, you can open the musicxml file using your favourite sheet music software.

Ofcourse some things like rit. and accel. are not working perfectly at the moment, but this saves a LOT OF EFFORT.
if you use it for a big project, you will know what a life saver it is.
